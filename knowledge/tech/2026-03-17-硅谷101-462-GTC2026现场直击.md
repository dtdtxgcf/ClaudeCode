## 摘要

硅谷101 泓君在 NVIDIA GTC 2026 大会现场，深度拆解黄仁勋主题演讲。2026 年被定义为"推理与智能体"统治世界的开端 —— 从 Vera Rubin 架构性能飞跃 350 倍，到整合 Groq 芯片打破吞吐量与延迟的矛盾，再到 OpenClaw 成为智能体时代的通用操作系统，黄仁勋描绘了一万亿美元 AI 基础设施蓝图。

- **OpenClaw 成为 Agent OS**：黄仁勋称 OpenClaw 为"人类历史上最受欢迎的开源项目"，对标 Linux/HTML，NemoClaw 企业版一键部署

## 详细内容

### 芯片与架构：从 Blackwell 到 Feynman

GTC 2026 的核心发布是 Vera Rubin 平台。该平台首次采用 LPDDR5 低功耗内存和 NVFP4 4 位精度浮点运算，45°C 水冷散热。Vera CPU 已进入全面量产阶段，性能比传统机架级 CPU 快 50%，效率是其两倍，预计 2026 年下半年交付。

NVIDIA 还公布了完整路线图：
- **Vera Rubin** (2026 H2)：NVLink 576 / LP3.5 架构
- **Vera Rubin Ultra** (2027)：Kyber 互联，144 颗 GPU
- **Feynman** (2028)：全新 GPU 架构，性能较 Hopper 提升约 900 倍

### Groq 整合：打破吞吐量与延迟的矛盾

NVIDIA 收购 Groq 后推出 Groq 3 LPU 芯片，500MB 片上 SRAM，1.2 PetaFLOPS FP8 性能。该芯片专攻低延迟推理场景，与 Vera Rubin GPU 形成互补 —— GPU 负责高吞吐量训练和推理，LPU 负责超低延迟 Token 生成。

### Token 经济学与 AI 工厂

黄仁勋强调，这些设施不应再叫"数据中心"，而是"AI 工厂"—— 其根本目的是生产 Token。Token 成本从固定模式转向动态定价，AI 推理成本正成为企业 IT 最大支出项。

### OpenClaw 与 Agent 生态

OpenClaw 在 GitHub 获得 247K+ stars，NVIDIA 联合创始人 Peter Steinberger 推出 NemoClaw 企业版平台，实现 OpenClaw 一键部署。黄仁勋将 Agent 定位为下一代计算范式，断言传统 SaaS 将被 Agent 替代。

NeMoTron 系列开源模型（300+ 款）支撑多行业 Agent 应用，其中 NeMoTron 3 Ultra 被称为"历史上最好的开源模型"。

### Physical AI 与机器人

NVIDIA 升级 Project GR00T 通用机器人基础模型。迪士尼雪宝机器人成为 GTC 现场最大亮点 —— 25 个自由度关节系统、Jetson 芯片驱动，通过强化学习和仿真训练实现动画角色的鲜活还原。

### CUDA 二十年与软件生态

CUDA 从 2006 年至 2026 年累积二十年生态壁垒，NVIDIA 定位为"唯一同时支持 PyTorch/JAX 的 GPU 厂商"。DSX 平台统一 AI 数据、工程、交换、优化框架。企业合作方面，IBM watsonx SQL 查询速度提升 5 倍、成本降 83%。

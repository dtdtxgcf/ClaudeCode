# 会议要点

### 战略选择与经营哲学
会议聚焦于公司应专注于高利润的“小而美”模式，而非盲目追求规模。
-   专注高利润细分市场，其盈利能力远超规模大但利润薄的企业。
-   选择比努力更重要，应果断放弃衰退市场，转向医美等新兴高门槛领域。
-   凭借过硬产品和技术壁垒吸引客户，实现“款到发货”的健康现金流。
-   公司核心资产是长期共事且愿景一致的精干团队。
### 核心能力与竞争壁垒
公司的长期优势源于技术积累与人才传承，而非暂时的市场地位。
-   全栈工程能力是实现产线快速自建与迭代的核心优势。
-   早期“失败”项目积累的核心工艺，可能成为进入新市场的关键技术储备。
-   通过提升医疗器械准入许可等级，可构建高市场门槛以获得定价权。
-   核心技术人员能培养团队，将产线模式复制到全国，实现知识规模化。
### 增长路径与资本策略
会议明确了内生增长与外延增长并行的路径，并强调了合作的重要性。
-   优先从业务层面开始合作，为未来股权整合建立信任基础。
-   企业可通过整合产业链上的合作伙伴，共同进入资本市场。
-   控股权的变更必然导致经营理念的碰撞，应谨慎出让经营权。
-   承担国家级重大专项课题，是证明公司“科创属性”的关键。

# 个人信息流系统 — 「AI时代的个人TikTok」

## Context

Boss 面临 AI 时代信息焦虑：信息源分散（播客/公众号/视频号/YouTube），高价值内容收藏了不看，缺少从「发现→筛选→消化→归档」的完整流水线。已有播客系统（28源+评分）跑通，现在要扩展为覆盖所有信息源的个人信息流系统。

**核心痛点**：收藏 = 坟墓。刷到好东西收藏了再也不看，因为收藏那一刻没有做任何加工。

## 系统架构

```
信息源层（播客28源 + 公众号 + 视频号 + YouTube + X/即刻）
    ↓ 采集（微信凡凡 / Claude Code / 定时扫描）
处理层（OCR → 搜索原文 → 评分/判断）
    ↓ 结构化
消化层（摘要版 / 要点版 / 全文版 / 音频版NotebookLM）
    ↓ 归档
知识库层（Obsidian knowledge/ + [[双链]] + 每日日报）
```

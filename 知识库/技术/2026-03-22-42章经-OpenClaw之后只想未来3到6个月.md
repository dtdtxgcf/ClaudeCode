## 摘要

Sheet0 创始人王文锋与曲凯深度对谈 OpenClaw 带来的 Agent 新浪潮。核心判断：所有 Agent 本质上都是 Coding Agent；垂直 Agent 和 SaaS 都将被 Coding Agent + Skill 替代；未来的关键机会是"管 AI 的 AI"（Agent Harness）。文锋的创业思路从"预判 5-10 年"转向"只看 3-6 个月"，以跟随为主、预判为辅。

## 要点

### 核心判断
- **所有 Agent 本质上都是 Coding Agent**：OpenClaw 核心就是 ClawPad 这个 Coding Agent，加上 Memory 和集成
- **垂直 Agent 需被高度怀疑**：Coding Agent + Skill 基本能覆盖垂直 Agent 的效果
- **SaaS 将被颠覆**：软件的 Coding 价值被 AI Coding 替代，know-how 价值被 Skill 替代
- **未来软件是"日抛式"的**：按需生成、用完即弃

### OpenClaw 的意义
- 第一个把最新模型 Coding 能力压到极致的产品形态
- 让大家看到 Proactive Agent（有主动性、能自我迭代的 Agent）长什么样
- 最大震撼不是产品本身，而是作者单日 commit 最高 1600 次（≈ 3-4 人团队一年工作量）
- 类比 Linux 内核，接下来会出现大量"发行版"

### 长程任务突破
- 从几十步 → 今年可能几百步甚至上千步
- 解决了准确率下降问题：状态落到文件上（而非内存），Agent 可自我修复
- 关键进步：不再是人控制 context，而是让 Agent 自己维护 context
- 印证了 "Less structure, more intelligence"

### Proactive Agent
- 两类主动性：定时重复任务（被动触发的主动）→ 基于历史交互主动判断需求
- OpenClaw 最大贡献：让大家看到"AI 管 AI"的可能性
- 从"人管 AI"（Manus）→ "AI 管 AI"（OpenClaw）

### Agent Harness（新概念）
- 2025 年 9 月硅谷出现的概念，比喻为"马鞍"
- 面向终端用户的脚手架，帮助搭建适合自己业务的 Agent 系统
- 不同于传统 Infra → SaaS → 用户的分层

### Coding Agent 三阶段
1. **Copilot**：代码补全
2. **Coding Assistant**（Claude Code）：程序员主动 prompt
3. **AI 管 AI**：Agent 自己发现、澄清需求，调度执行

### 创业心态转变
- 从"预判 5-10 年" → "只看 3-6 个月"
- 从"优化赔率" → "优化胜率"
- "预判为辅，跟随为主"
- 放下 ego，不要为了差异化过度预判

### 人才与效率
- 7 人团队 ≈ 过去 30-50 人的产出
- 个人效率比去年提升 10 倍
- 过去一年的产品，现在两周就能完成
- 招人极其谨慎：关键是"悟性"和默契
- 按 Token 消耗分层：日消耗 1 亿 Token 的用户 ≈ SaaS 时代的世界 500 强

### 对社会影响的担忧
- Agent 效率提升可能导致大规模失业 → 消费需求萎缩 → 负反馈循环
- "只看 3-6 个月"也是因为看不清更远的社会影响

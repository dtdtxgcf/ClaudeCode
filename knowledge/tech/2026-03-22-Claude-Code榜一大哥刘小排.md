# 揭秘 Claude Code 榜一大哥：对话刘小排

## 摘要

十字路口 Crossing 播客对话刘小排——Claude Code 全球 token 消耗量榜一用户。刘小排是非程序员出身的 AI 创业者，利用 Claude Code 独立完成产品洞察、开发到盈利的全过程，旗下 Raphael AI、AnyVoice、Fast3D 等产品增长迅速。节目深入探讨了他如何将 Claude Code 用到极致，以及 AI 创业的实战经验。

## 要点

- Claude Code 不只是写代码的工具，而是一个**通用 Agent 工具**，从调研到开发都能做
- 只要在虚拟世界中，任何有标准操作程序（SOP）的事情都可以通过 Claude Code 实现自动化
- Claude Code 的核心价值在于**可控性**——允许用户根据需要为其提供工具，实现无限级扩展，区别于 Manus 等内置工具受限的 Agent
- AI 创业不一定不赚钱，关键是降低营销和人力成本，从第一天就开始盈利
- 避免屎山代码的方法：先把需求文档写清楚（最好配图），再和 AI 讨论需求细节

## 详细内容

### 背景故事

Anthropic 发布公告称工程师在后台发现一个异常账户，以 7x24 小时的速度消耗 Claude 模型算力。在每月 200 美元的套餐中，消耗了价值 **5 万美元**的模型使用量，导致 Anthropic 不得不公开调整全球用户的速率限制。刘小排随后在 X 上认领了"榜一大哥"身份。

### 嘉宾：刘小排

- 非程序员出身的 AI 创业者
- 旗下产品：**Raphael AI**、**AnyVoice**、**Fast3D**
- 公司仅六七人，但收入可养活三五十人规模的团队

### Claude Code 使用心得

1. **通用 Agent，不止于 Code**：别被 Claude Code 的 "Code" 这个单词迷惑，它是通用 Agent 工具
2. **SOP 自动化**：虚拟世界中任何有 SOP 的事情都能自动化
3. **可控性是关键**：可以根据需要为 Claude Code 提供工具，实现无限级扩展
4. **先读官方文档**：很多功能（如 7x24 运行）是官方宣传的功能，不是黑科技
5. **需求文档先行**：先在飞书里把需求文档写清楚，配上图，再和 AI 讨论细节，需求不清楚 = 屎山代码

### AI 创业观点

- 榜单头部 AI 产品不赚钱，但不代表 AI 创业不赚钱
- 关键是不乱花钱投放，降低营销和人力成本
- 从第一天就开始赚钱是完全可行的

## 摘要

MuleRun 创始人陈宇森（前长亭科技创始人，22 岁浙大毕业创业，5 年后卖给阿里云）分享了他对 AI Agent 交易平台的观察与创业实践。核心观点：Vibe Coding + Claude Code 大幅降低 Agent 创作门槛，非技术人员也能把工作流封装成 AI Agent，未来软件是"日抛式"的，Marketplace 将从货架形态转变为对话中触发交易。

## 要点

- **核心假设**：Vibe Coding 降低开发门槛 + Claude Code 带来 Agent 创作新范式 → 非技术人员也能构建 AI Agent 自动化个人工作
- **MuleRun 做两件事**：好的 Runtime、清晰的 Skills 定义、Prompt 的商业化
- **"日抛式软件"**：未来软件不再是长期维护的产品，而是按需生成、用完即弃
- **Marketplace 新形态**：不再是传统货架，而是在对话中触发交易
- **Claude Code 是拐点**：Agent 供给从不够丰富到 Claude Code 带来爆发
- **思路快速迭代**：两次访谈（25年12月 vs 26年1月）间，MuleRun 的方向已发生变化

# AI 播客知识采集系统 — 需求文档 v0.1

## 用户故事

> 作为一个关注 AI 领域的投资人/创业者，我希望用最少的时间，系统性地从播客中获取高质量信息，沉淀到我的知识库中。

## 用户画像

- 每周听 1-2 期 AI 播客
- 主要通过小宇宙/Apple Podcasts 发现内容
- 想留下的：核心观点、方法论、关键数据、人脉资源线索
- 痛点：信息源不够、好内容太多来不及听、听完不知道怎么高效整理

## 核心矛盾

**时间有限 vs 信息过载**——不是要听更多，而是要用更少时间获取更多价值。

## 三层闭环

```
筛选（这周听什么）→ 压缩（5分钟决定要不要深听）→ 沉淀（听完一键入库）
```

### 第一层：筛选

维护 AI 播客订阅清单，定期扫描最新一期，给出推荐摘要。

### 第二层：压缩

对感兴趣的某期，先搜索文字版生成结构化摘要，用户看完决定要不要完整听。

### 第三层：沉淀

截图/链接 → Claude Code 自动搜原文 → 整理入库 → 关联已有笔记（已有流程）。

## 摘要

浙大蓝莲花 CTF 战队出身的连续创业者陈宇森，22岁创办长亭科技（后卖给阿里云），现创办 MuleRun（骡子快跑）。核心假设：当 Vibe Coding 降低开发门槛、Claude Code 带来 Agent 创作新方法时，非技术背景的人也能把工作知识封装成 AI Agent。

## 要点

- **未来软件是「日抛式」的**：不需要长期维护的一次性 Agent 应用，按需生成按需丢弃
- **Marketplace 不再是货架**：未来 Agent 交易在对话中触发，不是传统 App Store 形态
- **MuleRun 产品架构**：每位用户分配 7x24 独立云端虚拟机，零门槛仅需浏览器
- **技术差异化**：context compression 和 memory 的实现方式
- **已验证场景**：短剧创作、游戏开发、跨境电商、金融投资
- **3.0 方向**：从「长任务执行」转向「主动式团队协作」— 多 Agent 在统一 IM 环境中协同
